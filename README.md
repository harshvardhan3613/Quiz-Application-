# Quiz Application

A simple and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**. This project allows users to test their knowledge of **HTML, CSS, and Python** through multiple-choice questions.

## Features

* Select a quiz category: HTML, CSS, or Python
* Multiple-choice questions
* Automatic answer checking
* Automatic score calculation
* Final result display
* Simple and attractive user interface
* No time limit

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was created as a **mini project to practice frontend web development**, especially HTML, CSS, and JavaScript concepts.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a browser or Live Server.
4. Select a category and start the quiz.
